📦 DATABASE: ITHelpDesk

Identity & roles (ASP.NET Identity)

AspNetUsers
Id, Email, FirstName, LastName, Department, PasswordHash, IsActive, CreatedAt
AspNetRoles
Id, Name (Admin, Agent, Employee, Manager)
AspNetUserRoles
UserId → Users, RoleId → Roles
AspNetUserClaims
UserId, ClaimType, ClaimValue

Lookup tables (PDF spec: Categories, Priorities, Statuses)

TicketCategories
Hardware, Software, Network, Email, Access Request, Other
TicketPriorities
Low, Medium, High, Critical
TicketStatuses
Open, In Progress, Pending, Resolved, Closed

Core (PDF spec: Tickets)

Tickets
Id, ReferenceNumber (TKT-2026-#####), Title, Description, CategoryId, PriorityId, StatusId, CreatedByUserId, AssignedToUserId, CreatedAt, ResolvedAt, ClosedAt

Related (PDF spec: Comments, Attachments, Notifications, ActivityLogs)

TicketComments
TicketId, UserId, Body, IsInternal
TicketAttachments
TicketId, FileName, StoredFileName, FileSizeBytes
TicketAssignments
TicketId, AssignedToUserId, AssignedByUserId, IsEscalation
TicketStatusHistory
TicketId, FromStatusId, ToStatusId, ChangedByUserId
Notifications
UserId, TicketId, Title, Message, IsRead
ActivityLogs
UserId, Action, EntityType, EntityId, IpAddress

System

SystemSettings
SettingKey, SettingValue
PasswordResetTokens
UserId, Token, ExpiresAt
KnowledgeBaseArticles
Optional — Title, Content, IsPublished
